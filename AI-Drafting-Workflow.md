# AI-Assisted Drafting Workflow

1. Choose a prompt from `Prompts/`.
2. Paste the relevant outline, research notes, and chapter metadata into GitHub Copilot Chat.
3. Ask Copilot to draft inside the current markdown file rather than generating content elsewhere.
4. Review every AI-generated section for accuracy, tone, and source alignment.
5. Record supporting sources in the chapter frontmatter and related research notes.
6. Summarize finished chapters into `Summaries/` for fast recall during revisions.
