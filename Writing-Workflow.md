# Writing Workflow

1. Start in `Book-Overview.md` and `Outline.md`.
2. Capture raw ideas in `Ideas.md` and longer notes in `Notes/`.
3. Research in `Research/` using the template to track sources and claims.
4. Create new chapter files from the chapter template with `scripts/new_chapter.py`.
5. Draft in markdown and keep one chapter per file.
6. Use frontmatter to track status, word count, revision stage, sources, and tags.
7. Move finished drafts into `Chapters/` and export outputs into `Exports/`.
8. Refresh `Progress.md` and `Manuscripts/Index.md` with the scripts in `scripts/`.
