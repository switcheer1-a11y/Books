# Example Research Note

## Question
Why is a markdown-first writing workflow effective for nonfiction books?

## Findings
- Plain-text files are resilient and easy to move between tools.
- Git history makes revision checkpoints and structural experiments easier to review.
- Separating drafts, chapters, and summaries reduces clutter during revision.

## Evidence
- Markdown files stay readable without specialized software.
- Version control offers low-friction recovery and comparison.

## Relevance to the Book
Useful for an introductory chapter about the writing system or for process notes included in an appendix.
