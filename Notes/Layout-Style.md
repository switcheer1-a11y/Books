# Layout Style

## Required Patterns
- Short paragraphs
- Frequent whitespace
- Fast Kindle reading rhythm
- Occasional visual callouts

## Reusable Blocks
DEBUG NOTE:
A concise reframe that sounds like a mental debugging insight.

REALITY CHECK:
A grounding observation that corrects distorted assumptions.

PATTERN:
A short chain that shows how one thought loop leads to another.

## Avoid
- workbook prompts everywhere
- therapy-session pacing
- dense academic explanation
- inspirational quote energy
