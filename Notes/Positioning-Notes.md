# Positioning Notes

## Category
Professional mental performance guide for developers.

## Not This
- motivational fluff
- generic self-help
- toxic positivity
- workbook-style daily maintenance

## This Instead
- rational explanation
- emotional recognition
- developer-native language
- calm, grounded clarity
- practical mental reframing backed by observable patterns

## Tone Rules
- No hype
- No therapy voice
- No academic jargon
- No preachy confidence language
- Write like a calm senior developer explaining the system
