# Revision Workflow

## Suggested Stages
- `draft`
- `self-review`
- `fact-check`
- `editorial`
- `revised`

## Revision Loop
1. Review the chapter summary and outline.
2. Check structure, clarity, and evidence.
3. Improve readability using the prompt templates.
4. Verify every factual claim against sources in `Research/` and `References/`.
5. Update `revision_stage`, `word_count`, and `sources_used` in frontmatter.
6. Commit revisions in small, chapter-focused Git commits.
